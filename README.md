# wiseman-extension
extension made for revealing wiseman answers.

# Installation steps

Requirements:

- Computer
- Google chrome
- Internet connection
- Some braincells

1. Download the extension [here](https://github.com)
2. Go to `chrome://extensions/` (Paste it in your url bar..)
3. Toggle 'Developer mode' in the top right corner in the page
4. Press 'Load Unpacked' (Top left corner)
5. Choose this folder you downloaded (**Extract** the downloaded `.zip` file into a regular folder on your computer first)
6. Use it like a normal chrome extension
